## Integrations

[Open all](#)

### How does Amazon MQ work with other AWS services?

Any application that runs on an AWS compute service, such as [Amazon EC2](/ec2/), [Amazon ECS](/ecs/), or [AWS Lambda](/lambda/), can use Amazon MQ. Amazon MQ is also integrated with the following AWS services:

- [Amazon CloudWatch](/cloudwatch/) - Monitor metrics and generate alarms
- [Amazon CloudWatch Logs](/cloudwatch/features/) - Publish logs from your Amazon MQ brokers to Amazon CloudWatch Logs
- [AWS CloudTrail](/cloudtrail/) - Log, continuously monitor, and retain Amazon MQ API calls
- [AWS CloudFormation](/cloudformation/) - Automate the process of creating, updating, and deleting message brokers
- [AWS EventBridge Pipes](https://docs.aws.amazon.com/eventbridge/latest/userguide/eb-pipes-mq.html) – Use Amazon MQ message brokers as a source
- [AWS Lambda](https://docs.aws.amazon.com/lambda/latest/dg/with-mq.html) - Use Amazon MQ message brokers as a source
- [AWS Identity and Access Management (IAM)](/iam/) - Authentication and authorization of the service API
- [AWS Key Management Service (KMS)](/kms/) - Create and control keys used to encrypt your data

### What compliance programs are in scope for Amazon MQ?

Amazon MQ is compliant or eligible for the following programs: 

- HIPAA eligible
- PCI DSS compliant
- SOC 1,2,3 compliant
- ISO 9001, 27001, 27017, and 27018 certified

For a complete list of AWS services and compliance programs, please see [AWS Services in Scope by Compliance Program.](/compliance/services-in-scope/)
