Este banco replica el formato del examen: un escenario de dos a cuatro frases en inglés ("A company is running…"), cuatro opciones plausibles de las que solo una es correcta, y un requisito final que casi siempre esconde el calificador decisivo (LEAST operational overhead, MOST cost-effective, highly available, decouple, minimize latency). Los distractores no son absurdos: son soluciones técnicamente posibles que violan algún requisito o añaden overhead innecesario — pasos manuales, infraestructura self-managed cuando se pide managed, sobre-arquitectura regional para un problema de una sola AZ — exactamente como los construye AWS. La respuesta correcta y la explicación quedan ocultas dentro del bloque desplegable de cada pregunta.

Cómo usarlo: primero responde sin abrir el bloque — decide una letra y justifícatela mentalmente antes de desplegar la solución. Después lee la explicación completa aunque hayas acertado: lo que entrena el examen no es la letra, sino reconocer la señal del enunciado que apunta a la respuesta y el motivo exacto por el que cae cada distractor. Anota el dominio de cada fallo y, si en un dominio fallas más de cuatro de quince, vuelve a sus páginas de tema antes de continuar. La cobertura temática sigue la distribución real del examen: D1 con IAM roles, SCP, KMS, WAF, Cognito, security groups y NACL; D2 con decoupling SQS, multi-AZ, RTO/RPO, failover de Route 53 y read replicas; D3 con performance de S3, tipos de EBS, ElastiCache, familias de EC2, Kinesis y ALB/NLB; D4 con S3 lifecycle, Spot y Savings Plans, VPC endpoints, right-sizing y Transit Gateway.

Cómo atacar cada pregunta
Lee primero la última frase del enunciado — la pregunta con su calificador — y solo después vuelve al escenario: saber si buscan least operational overhead, most cost-effective o minimize latency determina qué detalles del escenario importan. Subraya mentalmente ese calificador y elimina primero las opciones que lo violan aunque sean técnicamente correctas: pasos manuales, self-managed donde piden managed y sobre-arquitectura son la firma del distractor. Si quedan dos candidatas, compara cuál cumple todos los requisitos del enunciado — la respuesta correcta nunca sacrifica ninguno, y la incorrecta suele cumplir solo la mitad.

Dominio 1 · Design Secure Architectures (15 preguntas)

D1-Q01 A company is running a web application on Amazon EC2 instances in an Auto Scaling group. The application must upload daily reports to an Amazon S3 bucket. The security team requires that the application use temporary credentials only and that permissions follow the principle of least privilege. Which solution meets these requirements with the LEAST operational overhead?
  1. Create an IAM user with programmatic access keys, store the keys in the launch configuration of the Auto Scaling group and rotate them every 90 days.
  2. Create an IAM role with a policy that allows only the s3:PutObject action on the bucket, and attach it to the instances through an instance profile.
  3. Store the access keys of the root user in an encrypted environment variable on every instance.
  4. Configure the bucket policy to allow anonymous s3:PutObject access from the application subnet CIDR block.
Correcta: B
El enunciado pide credenciales temporales y least privilege: exactamente lo que da un rol IAM con instance profile, cuyas credenciales emite AWS STS y rotan automáticamente sin que la aplicación guarde nada. La política, además, se limita a una sola acción sobre un solo recurso. A usa access keys permanentes que hay que distribuir y rotar a mano — el anti-patrón clásico de credenciales en configuración. C es la versión agravada: keys del root user, la peor práctica posible. D abre el bucket sin autenticación alguna: ni least privilege ni credenciales temporales.
D1-Q02 A company uses AWS Organizations with more than 40 member accounts. The security policy states that resources may only be created in the us-east-1 and eu-west-1 Regions in every account, and member account administrators must not be able to override the rule. Which solution enforces this requirement centrally?
  1. Attach an IAM policy that denies the non-approved Regions to every IAM group in every member account.
  2. Use AWS CloudFormation StackSets to deploy the same environment in the two approved Regions of every account.
  3. Attach a service control policy (SCP) to the organization root or to the top-level organizational unit that denies all actions when aws:RequestedRegion is not us-east-1 or eu-west-1.
  4. Enable AWS Config rules in each account that detect resources outside the approved Regions and send a weekly compliance report.
Correcta: C
Las SCPs son los guardrails de permisos de Organizations: se aplican de forma centralizada y ningún administrador de una cuenta miembro puede superarlas, por muchos permisos IAM que tenga. Las palabras "centrally" y "cannot override" del enunciado apuntan directo a SCP. A depende de que cada grupo lleve la política adjunta, solo cubre usuarios IAM (no roles ni servicios) y es trivial de evadir creando otro grupo. B despliega infraestructura correcta pero no restringe nada: aprovisionar no es prohibir. D detecta el incumplimiento después de que ocurra y por cuenta — es detección, no prevención.
D1-Q03 A company stores encrypted objects in an Amazon S3 bucket in account A. The objects are encrypted with a customer managed key stored in AWS KMS. An application running in account B must download the objects. The bucket policy already grants s3:GetObject to the application role in account B, but the downloads fail with access denied errors. What should a solutions architect do to allow the downloads?
  1. Update the KMS key policy in account A to grant the role in account B the kms:Decrypt permission for that key.
  2. Disable server-side encryption on the bucket and re-upload the objects without encryption.
  3. Create an IAM user in account B with access keys that allow kms:Decrypt and s3:GetObject.
  4. Create a second copy of the KMS key in account B and configure the application to use that copy.
Correcta: A
Con SSE-KMS cada GET del objeto necesita dos autorizaciones: la del bucket (ya concedida con s3:GetObject) y la de la key (kms:Decrypt), que se evalúa en la key policy de la CMK que vive en la cuenta A. Un access denied con bucket policy correcta es la señal clásica de que falta el permiso de KMS. B elimina el cifrado y destruye el requisito de protección de datos. C reintroduce credenciales permanentes y no resuelve nada: la key sigue estando en A. D es imposible: las KMS keys no se copian entre cuentas, solo se comparten mediante su key policy.
D1-Q04 A company runs a public REST API behind an Application Load Balancer. During marketing events, a small number of clients generate thousands of HTTP requests per second from single source IP addresses, degrading the experience of legitimate users. The company wants to block the abusive clients automatically, with no human intervention. Which solution meets these requirements with the LEAST operational overhead?
  1. Manually add the offending IP addresses as deny rules in the security group of the ALB.
  2. Configure Network ACL rules on the ALB subnets to reject the offending IP addresses.
  3. Purchase AWS Shield Advanced and engage the Shield Response Team for every marketing event.
  4. Create an AWS WAF web ACL with a rate-based rule and associate it with the Application Load Balancer.
Correcta: D
La rate-based rule de AWS WAF cuenta las peticiones recibidas por cada IP en una ventana de 5 minutos y bloquea automáticamente cuando se supera el umbral: es el mecanismo gestionado pensado para abusos HTTP de capa 7 desde pocas fuentes. A y B son remedios manuales por IP, insostenibles ante direcciones cambiantes — y además los security groups no admiten reglas deny. C protege frente a DDoS volumétricos de L3/L4 con coste alto y procesos humanos de engagement: no es la herramienta para rate abuse de application layer.
D1-Q05 A startup is building a mobile application that requires user sign-up, sign-in, email verification and password recovery for hundreds of thousands of consumers. The team has only three developers and wants to avoid operating any authentication infrastructure. Which solution meets these requirements with the LEAST operational overhead?
  1. Create one IAM user per application consumer and enforce MFA on each account.
  2. Use Amazon Cognito user pools for sign-up, sign-in and password recovery, and expose the application through Amazon API Gateway.
  3. Deploy a self-managed Active Directory domain on two EC2 instances and federate the mobile application with SAML.
  4. Store user credentials in a DynamoDB table and validate passwords with a custom Lambda authorizer.
Correcta: B
Los user pools de Cognito son un directorio gestionado y escalable con los flujos pedidos listos para usar (registro, login, verificación de email, recuperación, MFA), sin servidores ni lógica de contraseñas que mantener: el calificador "avoid operating infrastructure" decide la pregunta. A confunde identidad de consumidores con identidad de infraestructura AWS y no escala en gestión ni en cuotas. C obliga a parchear y mantener alta disponibilidad de un directorio propio: el overhead máximo. D reinventa la autenticación — hashing, bloqueos, MFA — con superficie de error propia, justo lo que el equipo quiere evitar.
D1-Q06 A company runs a three-tier application in a VPC. Web instances run in public subnets, and application and database instances run in private subnets across two Availability Zones. The security team requires that only the application instances can initiate connections to the database on port 3306, and the rule must remain valid when Auto Scaling replaces instances with new private IP addresses. How should the solutions architect configure the security groups?
  1. Allow inbound TCP 3306 in the database security group from the CIDR range of the private subnets.
  2. Allow inbound TCP 3306 in the database security group from the security group of the web instances.
  3. Allow inbound TCP 3306 in the database security group from the security group of the application instances.
  4. Disable the security groups of the database instances and control access with a stateful Network ACL.
Correcta: C
Referenciar el security group de la capa de aplicación hace la regla independiente de las IP: cualquier instancia que use ese SG puede conectarse, y las sustituciones del Auto Scaling no rompen nada — es el patrón de capas por referencia que pide el requisito de reemplazo. A con el CIDR de la subnet permite conectar a cualquier recurso de esa subnet, no solo a la capa de aplicación, y caduca si cambian los rangos. B abre la base de datos también a la capa web y rompe el aislamiento entre tiers. D es falso de raíz: los NACL son stateless y los security groups no se pueden desactivar.
D1-Q07 A company's public application receives traffic from the internet through a Network Load Balancer. After a security incident, the team must immediately block one known malicious external IP address from reaching the EC2 instances, without affecting any other traffic. The instances' security groups allow inbound traffic only from the NLB. Which solution meets this requirement?
The EC2 instances run in private subnets associated with a custom Network ACL that currently allows all inbound traffic. The malicious host must be blocked before it reaches the instances, not after.
  1. Remove the security group rule that allows inbound traffic from the Network Load Balancer.
  2. Add the malicious IP address to the instances' security group as an inbound deny rule.
  3. Edit the private subnets' route table to blackhole traffic that is destined to the malicious IP.
  4. Add a numbered DENY rule for the malicious IP address at the top of the Network ACL associated with the private subnets.
Correcta: D
Solo los NACL pueden denegar por IP: se evalúan por número de regla en orden, y una deny en las primeras posiciones bloquea ese origen aunque los security groups lo permitan, sin tocar el resto del tráfico. B es la trampa de examen por excelencia: los security groups no tienen reglas deny, únicamente allow. A derriba la aplicación entera para bloquear una sola dirección. C actúa sobre tráfico saliente hacia un destino — blackholear rutas no filtra conexiones entrantes desde una IP concreta.
D1-Q08 An external auditor must review the compliance settings of an Amazon S3 bucket in a company's production AWS account for two weeks. The company requires temporary credentials that expire automatically, read-only access scoped to the bucket, and least privilege throughout. Which solution meets these requirements?
  1. Create an IAM role with a trust policy that lets the auditor's account assume the role, attach a policy that allows read-only access to the bucket, and let the auditor call AWS STS AssumeRole.
  2. Create an IAM user in the production account with read-only access to the bucket and send the access keys to the auditor.
  3. Share the root user credentials of the production account with the auditor for the two weeks of the review.
  4. Have a company administrator perform the compliance review and send the results to the auditor.
Correcta: A
El patrón cross-account con AssumeRole emite credenciales temporales que caducan solas (sesiones de 1 a 12 horas) y la política del rol se acota a solo lectura sobre un único recurso: least privilege sin nada que revocar a mano. B reparte access keys permanentes a un tercero — nunca caducan y hay que retirarlas manualmente. C es la violación más grave posible: el root user es todopoderoso y no se comparte. D no cumple el requisito de acceso del propio auditor y destruye la trazabilidad: CloudTrail registraría al empleado, no al auditor.
D1-Q09 A company runs an application on Amazon EC2 that connects to an Amazon RDS for MySQL database. The database credentials are hardcoded in the application configuration file. The security team requires automatic password rotation every 30 days, no downtime during rotation, and no credentials stored in code or configuration files. Which solution meets these requirements with the LEAST operational overhead?
  1. Store the password in a plaintext environment variable and update it manually every 30 days.
  2. Recreate the RDS instance with a new password every 30 days and update the application configuration each time.
  3. Store the credentials in AWS Secrets Manager and enable automatic rotation with an AWS Lambda rotation function.
  4. Store the credentials as an AWS Systems Manager Parameter Store SecureString and schedule a cron job that rotates the value.
Correcta: C
Secrets Manager rota el secreto en el intervalo que definas mediante una Lambda de rotación gestionada, sin downtime y sin tocar la aplicación, que recupera el valor en runtime: el requisito "automatic rotation" lo cumple de serie. A es manual y el valor queda expuesto en la definición del entorno. B es la opción destructiva: recrear la base de datos para rotar una contraseña añade downtime y trabajo masivo. D es técnicamente viable, pero Parameter Store no rota por sí mismo: hay que escribir y operar el cron job, exactamente el overhead que el enunciado pide evitar.
D1-Q10 A company must guarantee that every object uploaded to a regulated Amazon S3 bucket is encrypted with a specific customer managed KMS key. Uploads that request any other encryption method must be rejected. Which solution meets these requirements with the LEAST operational overhead?
  1. Enable default encryption with SSE-S3 on the bucket and send a warning email to developers who upload objects with other methods.
  2. Enable default encryption with SSE-KMS using the customer managed key, and add a bucket policy that denies s3:PutObject requests whose encryption headers do not specify that key.
  3. Enable S3 Object Lock in compliance mode for 10 years on every object.
  4. Enable bucket versioning and cross-region replication to a bucket that has default encryption enabled.
Correcta: B
Son dos controles complementarios: default encryption cifra por defecto con la CMK, y la deny condicional de la bucket policy rechaza cualquier PUT que explícitamente pida otra key u otro método de cifrado. Entre ambos cubren todos los caminos sin intervención humana. A no previene nada: un email de aviso no bloquea la subida, y SSE-S3 ni siquiera usa la CMK requerida. C implementa retención WORM (impide borrar y sobrescribir), pero no controla el método de cifrado. D replica objetos ya cifrados: protege durabilidad, no aplica la política de cifrado.
D1-Q11 A company serves a legacy web application through Amazon CloudFront with an Application Load Balancer as the origin. The application is known to be vulnerable to SQL injection attacks that arrive in crafted query strings, and the code cannot be changed for months. Which solution protects the application with the LEAST operational overhead?
  1. Configure Network ACL rules on the ALB subnets that inspect HTTP payloads for SQL injection patterns.
  2. Replace the Application Load Balancer with AWS Global Accelerator and add endpoint health checks.
  3. Increase the CloudFront price class to include all edge locations.
  4. Associate an AWS WAF web ACL with the CloudFront distribution and enable the managed rule group for SQL injection attacks.
Correcta: D
AWS WAF inspecciona peticiones HTTP/HTTPS de capa 7 (query strings, headers, body) y sus managed rules bloquean los patrones de inyección SQL conocidos sin escribir una línea de código: además, aplicado en la CDN, el ataque muere antes de llegar al origen. A es imposible: los NACL filtran por IP y puerto, no leen payloads de aplicación. B acelera y hace failover, pero no inspecciona contenido. C solo cambia la cobertura de edge locations: no añade protección alguna.
D1-Q12 A media company is building a mobile application. Authenticated users must upload short videos directly to a unique prefix of an Amazon S3 bucket, while guest users can only read a public catalog. The company wants signed-in users to receive short-lived AWS credentials scoped to their own prefix, without running any credential service. Which solution meets these requirements with the LEAST operational overhead?
  1. Use Amazon Cognito identity pools to obtain temporary AWS credentials for authenticated users, and scope write access with a policy that limits each user to the prefix derived from their identity ID.
  2. Distribute the access keys of a dedicated IAM user to each signed-in user through the application API.
  3. Run a credential broker on Amazon EC2 that creates an IAM user for every signed-in user.
  4. Give every signed-in user the credentials of a shared IAM role that has full write access to the bucket.
Correcta: A
Los identity pools de Cognito entregan a los usuarios autenticados (típicamente desde un user pool) credenciales temporales de AWS STS, y la política asociada puede condicionar los permisos al prefijo derivado de su identity ID: subida directa, aislada por usuario y sin servidores propios. B coloca access keys permanentes en el cliente: una fuga garantizada. C obliga a operar y escalar un broker — y sigue creando identidades permanentes. D comparte un rol con escritura amplia sobre todo el bucket: sin least privilege ni aislamiento entre usuarios.
D1-Q13 A company hosts an internal web application behind an Application Load Balancer in the us-east-1 Region. The application must be reachable over HTTPS on the company's custom domain, and the certificate must be renewed automatically before it expires. Which solution meets these requirements with the LEAST operational overhead?
  1. Generate a self-signed certificate on each EC2 instance and configure TLS in the operating system.
  2. Purchase a certificate from a third-party authority, import it to the ALB, and renew it manually every year.
  3. Request a public certificate for the custom domain from AWS Certificate Manager, validate it with DNS, and associate it with the ALB HTTPS listener.
  4. Request the certificate from ACM in the eu-west-1 Region and attach it to the listener of the ALB in us-east-1.
Correcta: C
ACM emite certificados públicos y los renueva automáticamente (validación DNS) para los servicios integrados como el ALB: cero gestión de expiración, que es el requisito diferencial. A rompe la confianza de los navegadores (certificado autofirmado) y además el TLS debe terminar en el balanceador, no instancia por instancia. B reintroduce compra, importación y renovación manuales: exactamente el overhead que hay que evitar. D falla por diseño: los certificados de ACM son Regionales y solo se asocian a servicios de su misma Región — la excepción global es CloudFront, que exige us-east-1.
D1-Q14 A company with 500 employees already authenticates them against its corporate identity provider. The employees need console and programmatic access to the company's AWS accounts, and the security team refuses to create or manage a second set of AWS identities. Which solution meets these requirements with the LEAST operational overhead?
  1. Create 500 IAM users, one per employee, and apply the corporate password policy to all of them.
  2. Configure IAM Identity Center to federate the corporate identity provider and map corporate groups to permission sets in the target AWS accounts.
  3. Deploy a bastion host that stores the corporate usernames and passwords and proxies AWS CLI sessions.
  4. Give all employees the credentials of a shared IAM administrative user protected with MFA.
Correcta: B
IAM Identity Center (AWS SSO) federa el IdP corporativo y mapea grupos a permission sets por cuenta: los empleados mantienen una única identidad (la corporativa) y el acceso AWS se otorga, audita y revoca de forma centralizada. A duplicaría 500 identidades y todo su ciclo de vida — altas, bajas, MFA — en AWS, justo lo que seguridad descarta. C no da acceso a la consola ni es federación: es un proxy que guarda contraseñas. D comparte credenciales administrativas: imposible atribuir acciones a personas y bloqueante para cualquier auditoría.
D1-Q15 During a security review, a company needs to identify every Amazon S3 bucket, KMS key and IAM role across its accounts that can be accessed from outside the account or from the internet, based on resource policies. The analysis must run continuously and report new findings automatically. Which solution meets these requirements with the LEAST operational overhead?
  1. Run a nightly AWS CLI script that downloads and reviews every resource policy in every account.
  2. Enable Amazon Macie in all accounts and export the findings to Amazon S3.
  3. Apply AWS Config conformance packs in every account and review the non-compliant resources weekly.
  4. Enable IAM Access Analyzer for the organization to continuously evaluate resource policies and report findings for external and public access.
Correcta: D
IAM Access Analyzer analiza las políticas de recursos (S3, KMS, SQS, Lambda, roles IAM…) aplicando razonamiento formal sobre los permisos efectivos y emite un finding por cada acceso externo o público, de forma continua y agregable a nivel de organización. A es una foto manual que caduca al primer cambio y hay que mantener en el tiempo. B no aplica: Macie descubre datos sensibles dentro de los objetos de S3, no analiza políticas de recursos. C valida configuraciones contra reglas de compliance — no calcula el acceso externo efectivo de cada recurso.

Dominio 2 · Design Resilient Architectures (15 preguntas)

D2-Q01 A retail company runs a web application that accepts customer orders. A separate fulfillment application processes the orders asynchronously, but during flash sales the fulfillment tier falls hours behind and the web tier returns 5xx errors to customers while it waits for synchronous responses. The company wants to keep accepting orders reliably even when fulfillment is slow or temporarily down. Which solution meets these requirements with the LEAST operational overhead?
  1. Introduce an Amazon SQS queue between the web and fulfillment tiers, and have the fulfillment workers consume messages at their own pace.
  2. Vertically scale the web instances so that they can retry the fulfillment API more times before failing.
  3. Schedule the fulfillment application to process the pending orders in a nightly batch from the orders database.
  4. Create a dedicated AWS Direct Connect link between the web tier and the fulfillment tier.
Correcta: A
La palabra mágica del enunciado es la dependencia síncrona que arrastra al productor: la cola persiste los pedidos y desacopla el ritmo del web tier del del fulfillment, de modo que la app sigue aceptando (y confirmando) aunque el procesador esté caído o arrastrando backlog — el patrón decoupling con buffer que domina este dominio. B escala el escalón equivocado: el problema no es CPU, es acoplamiento. C convierte un servicio interactivo en un batch nocturno: horas de retraso y una ventana de pérdida inaceptable para pedidos. D añade un enlace de red dedicado que no resuelve que la aplicación receptora no responda.
D2-Q02 A company runs its production database on Amazon RDS for MySQL in a single Availability Zone. The database must remain available if an AZ fails, the application must keep using the same connection endpoint, and failover must happen automatically without any application change. Which solution meets these requirements?
  1. Create a read replica in a second AZ and point the application to the replica endpoint.
  2. Modify the DB instance to a Multi-AZ deployment: RDS maintains a synchronous standby in another AZ and fails over by flipping the instance DNS endpoint automatically.
  3. Take hourly snapshots and, when an AZ fails, restore the latest snapshot into a new DB instance and update the connection string.
  4. Deploy a second independent database in another AZ and replicate it with AWS Database Migration Service (DMS).
Correcta: B
Multi-AZ es la respuesta canónica a "survive the loss of an Availability Zone": standby pasiva con replicación síncrona en otra zona y failover automático que conmuta el DNS que la aplicación ya usa, típicamente en el orden del minuto y sin pasos manuales. A desvía lecturas a una réplica: no acepta escrituras, su promoción no es automática y habría que cambiar el endpoint. C tiene un RTO de decenas de minutos y un procedimiento manual de restauración. D monta una réplica lógica por tu cuenta con DMS: mucho overhead y sin failover transparente ni consistencia síncrona.
D2-Q03 A finance application runs in a single AWS Region. The business can tolerate up to 4 hours of downtime and up to 1 hour of data loss after a Regional failure, and wants the LOWEST possible cost for disaster recovery. Which strategy meets these requirements?
  1. Multi-site active-active across two Regions with Route 53 latency routing.
  2. Warm standby: a scaled-down but complete copy of the environment always running in a second Region.
  3. Pilot light: a cross-region read replica always running, with the compute tier provisioned only on failover.
  4. Backup and restore: replicate data backups and snapshots to a second Region and rebuild the environment from CloudFormation templates during the disaster.
Correcta: D
Tolerar horas de RTO y de RPO sitúa el escenario en el peldaño más barato de la escalera de DR: solo datos replicados (backups copiados a otra Región) más plantillas para reconstruir bajo demanda — ningún número del enunciado exige infraestructura permanente. A y B corren infraestructura a plena escala o reducida de forma continua: un sobre-coste que un RTO de 4 horas no justifica. C mantiene una capa de datos siempre encendida para un RPO que se cumple de sobra con backups horarios.
D2-Q04 A company hosts its public application in two AWS Regions. All users must be served by the primary Region while it is healthy, and the secondary Region must take over automatically — without DNS changes or human intervention — when the primary Region fails. Which Route 53 configuration meets these requirements?

  4. A streaming AWS Glue job that micro-batches the events into S3.
Correcta: A
Firehose es un pipeline de entrega totalmente gestionado: ingesta continua, buffering por tamaño e intervalo, compresión, transformación opcional con Lambda y escritura en S3 sin un solo servidor que operar — la descripción literal del enunciado. B obliga a escribir, escalar y parchear los consumidores. C añade cola y orquestación de funciones para el mismo resultado con más piezas móviles. D es ETL gestionado más pesado y caro para lo que aquí es una entrega casi en crudo.
D3-Q14 A research team runs a tightly coupled HPC simulation across many Amazon EC2 instances that exchange small messages continuously. The job needs the lowest inter-node network latency and the highest per-node bandwidth, and the team accepts running all the nodes in a single Availability Zone. Which solution meets these requirements?
  1. Spread the instances across three Availability Zones for maximum fault isolation.
  2. Launch the instances in a cluster placement group on instances with enhanced networking.
  3. Place the instances behind a Network Load Balancer to accelerate east-west traffic.
  4. Use a partition placement group across two Availability Zones.
Correcta: B
El cluster placement group agrupa las instancias en una misma AZ con grupo de racks de alta banda, y junto al networking mejorado de las instancias Nitro minimiza la latencia y maximiza el throughput entre nodos: el patrón HPC clásico. A optimiza resiliencia, pero cruzar AZs añade latencia a cada mensaje — contradice el requisito de performance. C: el NLB balancea tráfico entrante de clientes, no la comunicación entre nodos. D particiona para workloads distribuidos grandes (HDFS, Cassandra) que necesitan aislamiento de fallos, no latencia mínima.
D3-Q15 A gaming company stores player progress in a DynamoDB table with provisioned capacity. During tournaments, the items of a handful of famous players receive most of the traffic, and the table returns ProvisionedThroughputExceeded errors even though overall utilization is low. Which action resolves the hot partition problem?
  1. Increase the table's provisioned throughput tenfold.
  2. Add a global secondary index on the player ranking attribute.
  3. Redesign the partition key — for example by appending a random suffix to the hottest keys — so that the traffic spreads across partitions.
  4. Switch the table to on-demand capacity mode.
Correcta: C
DynamoDB reparte la capacidad por particiones según el hash de la partition key: unas pocas keys calientes agotan su propia partición aunque la tabla total esté ociosa, y dispersar la key (sufijo aleatorio o clave compuesta) reparte esas lecturas y escrituras. A sube el coste de toda la tabla para resolver unas pocas keys. B sirve para patrones de consulta alternativos, no para redistribuir las particiones. D mitiga la gestión de capacidad, pero la partición caliente sigue existiendo y sigue limitando el throughput de esas keys.

Dominio 4 · Design Cost-Optimized Architectures (15 preguntas)

D4-Q01 A company stores application access logs in Amazon S3 Standard. The logs are queried frequently during the first 30 days, rarely during the following 90 days, and must be retained for five years for compliance, with retrieval only in case of an audit. Which solution minimizes the storage cost while meeting these requirements?
The compliance team requires retrieval of archived logs within 12 hours, and the access pattern above is stable and known.
  1. Keep all the logs in S3 Standard for the full five years.
  2. Transition all the logs to S3 One Zone-IA after 30 days and keep them there for five years.
  3. Configure a lifecycle configuration that transitions objects to S3 Standard-IA after 30 days and to S3 Glacier Deep Archive after 120 days.
  4. Store the logs in the S3 Intelligent-Tiering storage class for the whole retention period.
Correcta: C
El patrón de acceso es conocido y escalonado (30 días calientes, 90 templados, cinco años de archivo), y para patrones conocidos la lifecycle policy es la más económica: Standard, Standard-IA y Glacier Deep Archive — el tier de archivo más barato, cuya recuperación en horas encaja con la ventana de auditoría. A paga siempre el tier más caro. B abarata pero pierde la redundancia multi-AZ de unos datos que un compliance exige conservar. D es el candidato cuando el patrón es desconocido o cambiante: con un patrón fijo y documentado, las transiciones explícitas son más económicas y más fáciles de justificar ante el auditor.
D4-Q02 A company runs a stateless image-rendering job that processes millions of frames in parallel batches. Each task saves its progress to Amazon S3, so the job can be interrupted and resumed from the last checkpoint without losing work. The company wants the LOWEST possible compute cost. Which EC2 purchasing option meets these requirements?
  1. Spot Instances, with the fleet configured to handle the two-minute interruption notice by checkpointing and relaunching tasks.
  2. On-Demand Instances for the entire duration of the batch.
  3. Three-year all-upfront Reserved Instances sized for the full batch fleet.
  4. Dedicated Hosts reserved for the rendering fleet.
Correcta: A
El workload es interrumpible y tolerante a fallos (checkpointing en S3), y Spot ofrece los descuentos más profundos — hasta cerca del 90% frente a On-Demand en la página oficial de Spot: la combinación canónica de este dominio. B paga precio de lista para un trabajo que tolera interrupciones. C compromete capacidad 24/7 durante tres años para un job que corre unas horas al día: sobrecompra pura. D paga hosts físicos dedicados, una necesidad de licencias o compliance — no un mecanismo de ahorro.
D4-Q03 A company runs a steady-state business application on EC2: 40 m5.xlarge instances, 24 hours a day, all year. The finance team wants the largest available discount for this steady usage while keeping flexibility to move part of the workload to AWS Lambda and AWS Fargate during a planned modernization. Which option meets these requirements?
  1. Stay on On-Demand and rely on Auto Scaling to keep the bill low.
  2. Commit to a three-year Compute Savings Plan that covers the steady EC2 usage and also applies to Fargate and Lambda.
  3. Buy standard Reserved Instances for m5.xlarge instances with a one-year term.
  4. Run the whole application on Spot Instances with instance diversification.
Correcta: B
Los Compute Savings Plans comprometen un gasto por hora en dólares con el mayor descuento y la máxima flexibilidad: cubren EC2 sin importar familia, tamaño, sistema operativo o Región, y también aplican a Fargate y Lambda — justo la modernización prevista del enunciado. A no reduce el precio de instancias que corren 24/7: el Auto Scaling gestiona capacidad, no tarifa. C ata el descuento a una familia concreta, con un plazo menor (menos ahorro) y sin cobertura serverless. D introduce interrupciones en una carga de negocio estable que no las tolera.
D4-Q04 A company runs hundreds of EC2 instances in private subnets across two Availability Zones, and their traffic to Amazon S3 and Amazon DynamoDB goes through two NAT gateways. The NAT gateway data processing charges dominate the networking bill. Which solution reduces this cost with the LEAST operational overhead?
  1. Replace the NAT gateways with NAT instances running on Spot Instances.
  2. Move the instances to public subnets and assign them public IP addresses.
  3. Create a VPC peering connection to a services VPC in the same Region.
  4. Add gateway VPC endpoints for S3 and DynamoDB, and update the private subnets' route tables to use them.
Correcta: D
Los gateway endpoints enrutan el tráfico hacia S3 y DynamoDB por la red privada de AWS sin pasar por el NAT gateway ni pagar su cargo por GB procesado — el endpoint de tipo gateway para estos dos servicios no tiene coste adicional — y solo exigen crearlos y añadir la ruta. A reintroduce infraestructura propia (instancias que parchear y escalar) y baja la fiabilidad. B expone las instancias con IP pública: sacrifica el diseño de subred privada que ya tienes. C no aplica: el peering conecta VPCs entre sí, no da acceso al espacio de IPs de los servicios públicos de AWS.
D4-Q05 A company wants to find its EC2 instances, EBS volumes and Lambda functions that are over-provisioned, based on actual utilization metrics, and get concrete right-sizing recommendations. The team has no data engineering capacity to build its own analysis. Which service meets these requirements with the LEAST operational overhead?
  1. AWS Compute Optimizer, which analyzes CloudWatch utilization metrics and recommends optimal sizes and configurations.
  2. A third-party monitoring agent installed on every instance, with dashboards reviewed manually.
  3. Monthly manual queries over the Cost and Usage Report in Amazon Athena.
  4. AWS Budgets with alerts when the spend by service exceeds a threshold.
Correcta: A
Compute Optimizer analiza las métricas reales de utilización de instancias, volúmenes EBS y funciones Lambda (y también Auto Scaling groups) y produce recomendaciones de right-sizing listas para aplicar: el análisis que el equipo no puede construir ya está hecho. B añade agentes, dashboards y licencias que mantener cuando existe un servicio nativo. C analiza la factura, no la utilización por recurso: no distingue infrautilizado de bien dimensionado. D avisa cuando el gasto se dispara: no sugiere cómo corregirlo.
D4-Q06 A company runs 12 VPCs in the same Region. Today every pair of VPCs is connected with a non-transitive VPC peering connection, and the route tables are becoming impossible to maintain. The company wants a hub-and-spoke network in which any VPC can communicate with any other through a central point, including VPCs added in the future. Which solution meets these requirements with the LEAST operational overhead?
  1. Create the remaining VPC peering connections (up to 66 for 12 VPCs) and update every route table on each change.
  2. Route the inter-VPC traffic through public IP addresses over the internet.
  3. Attach all the VPCs to an AWS Transit Gateway and use its route table to control the traffic between them.
  4. Consolidate all the workloads into a single large VPC with one subnet per application.
Correcta: C
El Transit Gateway centraliza la conectividad en estrella: cada VPC mantiene un solo attachment, el enrutamiento entre VPCs es transitivo por diseño y añadir una VPC nueva es un attachment — no N peerings ni rutas nuevas repartidas por doquier. A escala cuadráticamente (66 peerings para 12 VPCs) y cada cambio toca todas las tablas. B manda el tráfico por internet: inseguro, variable y con coste de data transfer. D sacrifica el aislamiento de red (blast radius, seguridad por VPC) para ahorrar administración.
D4-Q07 A startup runs a reporting database that is used only a few hours per week during board meetings, with demand that swings from near zero to short spikes. The company wants to pay for database capacity only while it is actually consumed, with automatic scaling and no servers to manage. Which solution meets these requirements with the LEAST operational overhead?
  1. An always-on Amazon RDS instance sized for the peak of the meetings.
  2. An Amazon Aurora Serverless v2 cluster, which scales capacity in ACUs with demand and shrinks down to a small baseline when idle.
  3. A self-managed PostgreSQL cluster on Spot EC2 instances.
  4. An Amazon Redshift cluster paused between meetings.
Correcta: B
Aurora Serverless v2 ajusta la capacidad en ACUs de forma fina y se factura por el uso por segundo, escalando con la demanda y encogiéndose hasta el mínimo cuando no hay tráfico: perfecto para workloads intermitentes e impredecibles sin administrar servidores. A paga 24/7 una instancia dimensionada para picos de unas horas semanales: infrautilización total. C agrega toda la operación de base de datos (parcheo, réplicas, backups) sobre instancias interrumpibles: el overhead máximo. D es un data warehouse columnar para analítica masiva, no un sustituto del reporting transaccional, y su modelo de pausa no encaja con picos cortos.
D4-Q08 A finance team must receive an email notification when the current month's spend is forecast to exceed USD 10,000 and also when the actual spend crosses 80% of that budget, with a breakdown by service. Which service meets these requirements with the LEAST operational overhead?
  1. A CloudWatch billing alarm on the total estimated charges metric.
  2. A weekly cron job that parses the monthly invoice and sends the email.
  3. A daily manual review of the Billing console by the finance team.
  4. AWS Budgets with alert thresholds on actual and forecasted spend, filtered by service.
Correcta: D
AWS Budgets define umbrales sobre el gasto real y sobre el forecast, con filtros por servicio, cuenta o tags, y notifica por email o SNS cuando se cruzan: los dos disparadores del enunciado con configuración pura. A (la billing alarm de CloudWatch) solo dispara sobre una métrica estimada del total, sin desglose por servicio ni proyección a fin de mes. B construye y opera un pipeline propio para algo que ya existe como servicio. C es vigilancia manual: no escala ni alerta a tiempo.
D4-Q09 A company needs an hourly, per-resource cost breakdown, with resource tags included, queryable with SQL over the last 12 months. Which solution meets these requirements with the LEAST operational overhead?
  1. Enable the AWS Cost and Usage Report with resource IDs and tags, deliver it to Amazon S3, and query it with Amazon Athena.
  2. Download the monthly PDF invoices and parse them with a script.
  3. Schedule AWS Budgets reports with daily granularity.
  4. Review the Cost Explorer dashboard every month.
Correcta: A
El CUR con recursos y tags es la fuente de máxima granularidad de la facturación — línea por hora y por recurso — y Athena lo consulta con SQL sobre el histórico completo almacenado en S3: el estándar de analítica de coste en AWS. B parsea PDFs: frágil y sin granularidad horaria ni tags. C resume el gasto contra presupuestos: no da detalle por recurso. D es cómodo para tendencias agregadas de consumo, pero no entrega la granularidad por recurso etiquetado consultable con SQL sobre el histórico.
D4-Q10 A company uploads thousands of files per day to Amazon S3, but nobody knows which objects will be accessed frequently: some are read daily, others go untouched for months. The company wants automatic cost optimization without defining lifecycle rules or analyzing access patterns. Which solution meets these requirements with the LEAST operational overhead?
  1. Store all the objects in the S3 Glacier Instant Retrieval storage class.
  2. Analyze a year of access logs first, then write a lifecycle policy per prefix.
  3. Store the objects in the S3 Intelligent-Tiering storage class.
  4. Store all the objects in S3 One Zone-IA.
Correcta: C
Intelligent-Tiering mueve cada objeto entre los tiers de acceso frecuente e infrecuente según su patrón real de acceso, sin fees de recuperación y sin configuración por prefix: la automatización exacta que pide un patrón desconocido. A: Glacier Instant Retrieval está pensado para archivo con accesos poco frecuentes — pagaría retrieval por GB en cada lectura diaria. B exige el análisis previo y las reglas que el enunciado descarta explícitamente. D pierde la resiliencia multi-AZ y penaliza con fees de recuperación los objetos que resulten calientes.
D4-Q11 A company runs a REST API that averages 5 requests per minute but spikes to thousands of requests per second for a few hours during marketing campaigns. Today the company pays for 10 permanently provisioned EC2 instances. The application is stateless and can be refactored into functions. Which solution minimizes cost while handling the spikes?
The endpoints are dynamic and per-user, so responses cannot be cached at a CDN.
  1. Keep 100 EC2 instances always provisioned to absorb the spikes.
  2. Refactor the API to run on AWS Lambda behind Amazon API Gateway, which scales with requests and generates no compute cost while idle.
  3. Buy three-year Reserved Instances for the 10 current instances and add On-Demand capacity during campaigns.
  4. Put the EC2 fleet behind CloudFront and cache every API response at the edge.
Correcta: B
El perfil — casi ocioso con picos extremos — es el caso ideal de Lambda: escala por petición, se factura por invocación y en reposo no genera coste de cómputo, eliminando las 10 instancias permanentes. A paga siempre el tamaño del pico: carísimo para una media de 5 rpm. C mantiene instancias subutilizadas y solo abarata el tramo estable — el pico seguiría pagando On-Demand. D: el propio enunciado descarta el cacheo (respuestas dinámicas por usuario), y una CDN no sustituye la capacidad de cómputo.
D4-Q12 A company has 200 Amazon EBS gp2 volumes across its AWS accounts and wants to reduce EBS costs without changing the performance of its general-purpose web and application workloads. Which action meets these requirements with the LEAST operational overhead?
  1. Snapshot and recreate all the volumes as io2 Block Express.
  2. Migrate all the data to st1 HDD volumes.
  3. Downsize every volume to the minimum size that fits the current data.
  4. Change the volume type of each existing volume from gp2 to gp3 with an in-place modify-volume operation.
Correcta: D
gp3 ofrece el mismo perfil de SSD de uso general — con margen de IOPS y throughput provisionables incluso mayor que gp2 — a un precio por GB menor, y la conversión es una operación en vivo con Elastic Volumes: sin recrear volúmenes ni detener instancias. A es el tier premium de IOPS: coste muy superior sin necesidad alguna. B: los HDD no valen para el random I/O de apps interactivas ni como boot volume. C reduce la capacidad, no el precio por GB, y puede dejar las aplicaciones sin espacio.
D4-Q13 A new mobile app had near-zero traffic for weeks until a viral campaign generated a 100x spike in DynamoDB reads and writes, causing throttling. The team cannot predict future traffic and does not want to manage capacity settings. Which capacity mode for the table meets these requirements with the LEAST operational overhead?
  1. On-demand capacity mode, which serves any level of traffic without capacity planning.
  2. Provisioned capacity mode with 10 times the current peak reserved.
  3. Provisioned capacity mode with broad auto scaling limits.
  4. A DynamoDB Accelerator (DAX) cluster sized for the viral peak.
Correcta: A
On-demand factura por petición y absorbe cualquier pico sin configurar WCU/RCU ni alarmas: está diseñado para tráfico desconocido o muy variable, que es literalmente el enunciado. B sobreaprovisiona capacidad pagada por adelantado para picos infrecuentes: desperdicio garantizado. C mitiga, pero sigue exigiendo definir límites y tiempos de reacción que llegan tarde ante un pico 100x. D cachea lecturas: no ayuda con las escrituras ni elimina la gestión de capacidad.
D4-Q14 A small team runs a batch container workload a few times per day. The team does not want to provision, patch or scale any EC2 instances, and prefers to pay only for the CPU and memory that each task actually consumes while it runs. Which compute option meets these requirements with the LEAST operational overhead?
  1. An Amazon ECS cluster of self-managed EC2 instances that the team launches for each batch.
  2. An always-on Amazon EKS cluster with one managed node group.
  3. Amazon ECS tasks launched on AWS Fargate, paying per vCPU and memory per task.
  4. One large dedicated EC2 instance that runs all the batch jobs.
Correcta: C
Fargate es el runtime serverless de contenedores: sin instancias que administrar y facturación por tarea (vCPU y memoria por segundo) — el ajuste natural para un batch intermitente de un equipo pequeño. A obliga a lanzar y operar instancias para cada tanda. B mantiene un plano de control de Kubernetes con nodos permanentes para un trabajo de minutos al día: infraestructura desproporcionada. D conserva una instancia grande siempre encendida para tareas puntuales — y además hay que parchearla.
D4-Q15 An internal business application is used Monday to Friday from 08:00 to 18:00 and is completely idle at nights and weekends. It runs on an Auto Scaling group with 6 instances. The company wants to reduce cost without changing the application and without introducing interruption risk. Which solution meets these requirements with the LEAST operational overhead?
  1. Purchase three-year Reserved Instances for the 6 instances.
  2. Configure scheduled scaling on the Auto Scaling group: full capacity during business hours and a minimum of zero instances at nights and weekends.
  3. Switch the Auto Scaling group to Spot capacity with instance diversification.
  4. Terminate the instances every evening with a script and relaunch them every morning.
Correcta: B
Con un patrón horario conocido, el scheduled scaling recoloca la capacidad automáticamente — mínimo de cero fuera del horario y capacidad completa antes de las 08:00 — con ahorro real sin intervención humana ni cambios en la app. A compromete y paga capacidad 24/7 para una aplicación que se usa unas 50 horas a la semana. C introduce riesgo de interrupción que el enunciado descarta expresamente. D es operación manual diaria: el anti-patrón de overhead, y sin garantía de capacidad a primera hora.
